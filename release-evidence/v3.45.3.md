## Scope

v3.45.3 corrects the public package boundary after v3.45.0-v3.45.2 shipped an internal built-in Playbook template surface. The patch removes that template from the public source/docs/status/CLI/package surface and adds build-artifact private-term scanning to the release path.

## Changes

- Removed the internal built-in Playbook template from `core.py`, status output, CLI help, README command examples, changelog wording, and v3.45.0 release evidence wording.

## Release Notes Draft

v3.45.3 is a publication-boundary correction release.

It removes an internal built-in Playbook template from the public package surface and keeps the public product focused on generic Playbook engine, CLI, schema, and metadata-only management capabilities.

This release also hardens the publishing pipeline: source sanitization now runs in internal strict mode, built wheel/sdist artifacts are scanned with maintainer-local private-term rules before publishing, and release evidence must record an `artifact-private-scan` pass before CI will publish.

No publishing, tag creation, registry update, or other irreversible action is authorized by this evidence file alone.
