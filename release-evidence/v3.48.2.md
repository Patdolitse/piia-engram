## Scope

v3.48.2 is an OpenClaw-compatible bridge hardening patch. During local
OpenClaw validation, the static `MEMORY.md` export was found to include staging
lessons. The fix keeps the bridge conservative: only `tier=verified` and
`status=active` lessons/decisions are exported, and the generated `MEMORY.md`
file is capped at 32 KiB with clipped summary/reasoning fields.

This release does not add MCP tools, change telemetry, touch remote services,
alter permission/governance defaults, migrate user data, or change retrieval
ranking. It only tightens the OpenClaw-compatible file bridge and documents the
client-validation protocol.

## Release Notes Draft

### English

Engram v3.48.2 hardens the OpenClaw-compatible file bridge. `MEMORY.md` exports
now include only verified, active lessons and decisions; staging, pending,
archived, rejected, or otherwise non-active knowledge is excluded from the
static snapshot. The export is also capped at 32 KiB with clipped
summary/reasoning fields so external clients receive a bounded, readable
snapshot.

This is a local bridge-boundary patch: no telemetry schema change, no remote
service behavior change, no permission/governance default change, no user-data
migration, and no new agent-facing MCP tool.
