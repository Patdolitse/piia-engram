## English

Engram v3.52.0 is a minor release focused on reducing activation friction —
the time from `pip install` to "it remembered me across tools."

Highlights:
- **Risk-tiered write gate** — low/medium-risk new knowledge auto-absorbs as
  verified (audit-logged); only high-risk entries (credentials, commands,
  permission rules, MCP config) go to staging for human review. Unsupervised
  writeback hooks force staging regardless.
- **Auto-bootstrap on empty store** — the first `get_user_context` /
  `get_resume_brief` on a fresh install reads existing rule files (CLAUDE.md,
  AGENTS.md, .cursorrules) read-only and imports them, removing a manual step.
- **Setup consent-then-write** — `engram setup` now lists exact config paths it
  will modify, writes the MCP connection only after one-key confirmation (backed
  up first), and starts with a numbered language picker (中文 / English).
- **Public trust narrative aligned** — README, SECURITY, trust docs, and the
  bilingual quickstart honestly describe the new consent-then-write and
  risk-tiered approval model while retaining genuine guarantees.
