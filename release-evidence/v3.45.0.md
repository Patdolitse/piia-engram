## Release Notes Draft

v3.45.0 improves Engram's extraction and management workflows.

Automatic extraction now better separates durable knowledge from short-lived reminders: concrete metric-backed findings such as latency reductions or regression measurements are kept for review, while ephemeral personal reminders are filtered out of long-term memory unless they include durable evidence.

This release also adds metadata-only impact summaries for legacy Playbook scope apply/rollback previews, making future GUI confirmations safer for users with existing Playbooks. The management view and CLI now support filters for review kind, quality status, Playbook state, and scope while continuing to avoid stored knowledge bodies and local project paths.

Finally, the management and extraction changes were validated with focused local tests and narrow external review evidence.

No publishing, tag creation, registry update, or other irreversible action is authorized by this evidence file alone.
