## Release Notes Draft

### English

Engram v3.46.0 is the trust-and-readiness release.

It productionizes the memory trust loop: recall now carries provenance and freshness signals end to end, and new local surfaces expose deterministic recall and knowledge version chains without changing ranking defaults. A wide set of additive, proposal-only readiness surfaces ship as local CLIs and modules: `engram backup-plan`, `engram export-agents-md`, `engram lifecycle`, `engram integrity`, `engram dashboard`, `engram release-check`, and `engram telemetry-validate`. Each produces metadata-only previews that never mutate stored knowledge on their own.

This release also adds the opt-in telemetry analysis contract v1.1 (local derived buckets, transport schema unchanged) and hardens the `send_feedback` boundary with a fail-closed denylist so no free-text knowledge content leaves the local send boundary. The publish allowlist and positioning copy were refreshed to keep the public package surface honest.

Remote Cloudflare Worker / D1 migration, PyPI upload, MCP Registry and Glama updates, GitHub Release, Permission Profile vNext read-gate enforcement, Cursor live stop-hook write-back, and real multi-device sync remain user-gated and are not enabled by this release.
