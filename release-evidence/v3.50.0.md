## English

Engram v3.50.0 is a local release candidate for generated export redaction,
staging review separation, telemetry/dashboard alignment, and public claim
hardening. It adds a dynamic guard that renders real export surfaces from
synthetic Engram data before scanning them for sensitive strings, adds a
read-only `list_pending_staging` MCP tool, and keeps staging mutations gated
behind governance.

Highlights:
- Added `scripts/check_generated_export_redaction.py` and wired it into the
  release orchestrator, CI workflow, and publish workflow.
- Redacted export metadata-like fields such as domain labels, source-tool
  labels, section headers, stale titles, and related titles.
- Added `list_pending_staging` as a metadata-only read tool for reviewer and
  GUI queue flows.
- Kept `batch_review_staging` mutation behavior behind write governance.
- Refreshed public facts to 2830 passed, 2 skipped, 2832 collected tests, and
