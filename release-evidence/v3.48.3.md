## Scope

v3.48.3 is a local import candidate release. It closes the already-implemented
import/export refactor and safer local import preview work into a release-ready
checkpoint: full-backup export/import logic now lives in `ImportExportMixin`,
`engram import <backup.json>` defaults to a metadata-only dry run, and divergent
same-key lesson/decision candidates are surfaced as review-only version-chain
candidates without writing version-chain edges.

This release does not add MCP tools, change telemetry, touch remote services,
alter permission/governance defaults, migrate user data automatically, publish a
sync transport, or perform any remote release action. Mutating import remains an
owner CLI action requiring `--apply --yes`.

## Release Notes Draft

### English

Engram v3.48.3 prepares the local import path for safer backup restore and
future version-chain work. Full-backup import/export code is now isolated in
`ImportExportMixin`, while the existing `Engram.export_all()` and
`Engram.import_all()` APIs remain compatible.

The new `engram import <backup.json>` command is preview-first: by default it
returns a metadata-only dry run and does not change local data. A real import
requires `--apply --yes`; `--overwrite` is available for explicit replace-mode
imports. Dry-run import now also flags same-summary lessons and same-question
decisions with divergent semantic fields as `review_version_chain_candidate`
conflicts, without writing version-chain edges or mutating stored knowledge.

This is a local owner workflow release: no telemetry schema change, no remote
service behavior change, no permission/governance default change, no automatic
user-data migration, no sync transport, and no new agent-facing MCP tool.

### Chinese / 中文

Engram v3.48.3 为本地备份导入和后续版本链工作打下更安全的基础。完整备份的导入/导出代码已经拆到 `ImportExportMixin`，同时保持现有 `Engram.export_all()` 和 `Engram.import_all()` API 兼容。

新的 `engram import <backup.json>` 命令默认只做预览：返回 metadata-only 的 dry-run 结果，不改写本地数据。真正导入必须显式使用 `--apply --yes`；需要替换模式时可以再加 `--overwrite`。dry-run 导入现在还会把同 summary 的 lesson、同 question 的 decision 中语义字段不同的候选标记为 `review_version_chain_candidate` 冲突，但不会写入版本链边，也不会改变已存知识。

这是一个本地 owner 工作流版本：不改变 telemetry schema，不改变远端服务行为，不改变权限/治理默认值，不自动迁移用户数据，不发布同步传输能力，也不新增面向 agent 的 MCP 工具。
