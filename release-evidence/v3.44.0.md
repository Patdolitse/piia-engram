## Release Notes Draft

v3.44.0 tightens Engram's setup file-safety boundary.

By default, `engram setup` now leaves external MCP client config files byte-for-byte unchanged and prints guidance instead of silently rewriting them. Users who want Engram to update client config files can opt in explicitly with `--apply-external-config`; those writes now go through backup and redacted-ledger tracking first. The setup wizard also lets users choose the Engram data folder, including another drive or a custom location, and legacy configs keep their existing `ENGRAM_DIR` during repair or upgrade unless the user explicitly changes it.

This release also adds backups before replacing Engram-owned JSON stores and introduces metadata-only management action receipts for future UI-driven cleanup and review workflows.

Thanks to @syphrpunk for reporting the setup config overwrite behavior in GitHub issue #23. That feedback directly shaped the fail-closed setup behavior and backup coverage in this release.
