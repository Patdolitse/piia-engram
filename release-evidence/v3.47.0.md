## Scope

v3.47.0 is the telemetry completion release. It closes the Telemetry Analysis
Contract v1/v1.1 loop with local readiness validation, Worker dashboard v1.1
analysis tiles, a canonical remote-closeout runbook, privacy evidence, a local
Worker smoke harness, and documented dashboard access-control behavior.

The release does not change telemetry defaults: remote telemetry and feedback
remain opt-in, and the payload remains metadata-only.

## Release Notes Draft

### English

Engram v3.47.0 is the telemetry completion release.

It closes the Telemetry Analysis Contract v1/v1.1 loop: the local
`engram telemetry-validate --remote-readiness` command checks payload/schema,
Worker allowlists, migration ordering, dashboard wording, opt-in defaults, and
the metadata-only boundary without performing any network or D1 action. The
Worker dashboard now includes v1.1 analysis tiles for version adoption,
activation state, anonymous returning bucket, and error trend, all labelled as
anonymous daily-id buckets rather than unique users.

After explicit owner confirmation, the remote D1 schema and Worker deployment
were completed, a smoke event verified P0/P1 persistence and was deleted, and
the live dashboard was protected with `DASH_PASSWORD`. Telemetry remains opt-in
and metadata-only; Engram does not collect identity, project paths, prompts,
knowledge bodies, or free-text content.
