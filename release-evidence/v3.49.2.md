## English

Engram v3.49.2 is a patch release candidate for staging review, client
writeback, compatibility evidence, and public-fact hardening. It adds an
opt-in Cursor writeback hook that only writes extracted candidates into staging,
adds a metadata-only batch staging review tool, tightens Permission Profile
vNext staging visibility during review/publish stages, and fixes an encoding
repair false positive that could flag valid Chinese text with ordinary question
marks.

Highlights:
- Added a guarded Cursor writeback hook that is disabled by default,
  re-entry protected, transcript-bounded, and staging-only.
- Added `batch_review_staging` for metadata-only dry-run and confirmed
  approve/reject handling of staging lessons and decisions.
- Fixed encoding repair false positives around valid Chinese text and ordinary
  ASCII question marks.
- Hardened Permission Profile vNext so `staging_optin` cannot override
  review/publish-stage staging exclusion.
- Locked setup-wizard doctor probes for supported MCP entry shapes and bounded
  `--help` checks.
- Refreshed continuity/compatibility evidence while keeping OpenClaw claims to
  L3 static snapshot A/B only.
- Refreshed public facts to 2782 passed, 2 skipped, 2784 collected tests, and
  82 MCP tools: 17 core plus 65 advanced.
