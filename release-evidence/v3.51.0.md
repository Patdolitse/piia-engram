## English

Engram v3.51.0 turns the memory-quality work into a reproducible release gate.
It adds deterministic recall evaluation, a read-only admission guard, separate
held-out memory fixtures, and a single memory eval suite that now runs before
release.

Highlights:
- Added Recall Eval v1: a synthetic, public-safe, ID-scored benchmark for real
  `search_knowledge` results without live stores, network calls, or LLM judges.
- Added Admission Guard v1: a read-only, metadata-only guard for candidate
  memories, routing them to `accept`, `stage`, `reject`, `duplicate`, or
  `review_update`.
- Added held-out recall/admission fixtures covering cross-tool source signals,
  superseded memory chains, project scope, Chinese aliases, and near-miss
  negatives.
- Added `scripts/run_memory_evals.py` and wired it into CI, the publish workflow,
  and the release orchestrator.
- Fixed a release-authorization conflict miss: phrases like "without user
  confirmation" now route to update review, while phrases such as "without
  downtime" remain non-conflicts.
- Fixed eval CLI source drift by making eval scripts prioritize the worktree
  `src/` path.

## Chinese

Engram v3.51.0 把记忆质量评测从一次性本地验证，升级为可复现的发布前 gate。
本版本新增确定性 recall eval、只读 admission guard、独立 held-out 记忆评测集，
并把统一 memory eval suite 接入发布链。

重点：
- 新增 Recall Eval v1：使用合成、公开安全、ID 打分的 fixture，验证真实
  `search_knowledge` 结果；不使用真实用户存储、网络调用或 LLM judge。
- 新增 Admission Guard v1：只读、metadata-only 的候选记忆入库闸，将候选路由到
  `accept`、`stage`、`reject`、`duplicate` 或 `review_update`。
- 新增 held-out recall/admission fixture，覆盖跨工具来源信号、版本替代链、
  项目隔离、中文别名和近似负例。
- 新增 `scripts/run_memory_evals.py`，并接入 CI、publish workflow 和
  release orchestrator。
- 修复发布授权冲突漏判：`without user confirmation` 这类短语会进入 update
  review；`without downtime` 这类正常部署表达不会误报冲突。
- 修复 eval CLI 源码漂移：eval 脚本现在优先加载当前工作树 `src/`，避免误用已安装旧包。
